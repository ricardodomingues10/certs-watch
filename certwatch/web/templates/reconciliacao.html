Como funciona

Copie os ficheiros (CSV ou Excel) para import/ na pasta da aplicação no servidor. O nome do ficheiro indica a fonte: {% for label, prefix in prefixes.items() %}{{ prefix }}* = {{ label }}{{ ', ' if not loop.last else '.' }}{% endfor %} Em cada fonte é usado o ficheiro mais recente. Um ficheiro igual ao anterior não é lido de novo.

São reconhecidas as colunas das exportações do certutil (Issued Common Name, Certificate Expiration Date, Serial Number, Request Disposition) e do AVI (Subject_CommonName, Validity_NotAfter, Issuer_CommonName). Pedidos revogados ou não emitidos são ignorados. Datas DD/MM/AAAA nunca são trocadas.
