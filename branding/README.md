# Marca do cliente

Coloque aqui o logo do cliente com um destes nomes: `logo.svg`, `logo.png` ou `logo.webp`
(fundo transparente, até 2 MB). Aparece no topo da coluna de navegação, com o nome definido
em `CERTWATCH_CLIENT_NAME` no `.env`.

Os ficheiros de logo não vão para o repositório (estão no `.gitignore`): cada instalação tem o seu.
